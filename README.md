# MyHandy - Голосовой ввод текста

MyHandy — это скрипт Python для голосового ввода текста, который записывает аудио, распознает речь с помощью модели ONNX ASR и автоматически вставляет распознанный текст в активное приложение.

> **Примечание:** Этот проект является отсылкой к проекту [Handy](https://github.com/cjpais/Handy). Однако оригинальный Handy не заработал на моем Ubuntu и не работал даже на Windows (с аудио через RDP), поэтому появился этот проект в котором я попробовал его сделать в стиле unix-way (ну я так вижу)

## Как это работает

### Основные функции

1. **Запись аудио и распознавание речи**
   - Скрипт использует `arecord` для записи аудио с микрофона (16kHz, моно, 16-bit)
   - Распознавание речи (по умолчанию) выполняется с помощью библиотеки `onnx_asr` и модели GigaAM v3 E2E CTC
   - Модель загружается из директории `./models/`

2. **Механизм блокировки (Lock File)**
   - Скрипт использует файл блокировки (по умолчанию `/tmp/myhandy.lock`) для управления единственным экземпляром
   - При повторном запуске скрипт отправляет сигнал SIGUSR1 уже запущенному процессу и завершает работу
   - Это позволяет использовать один и тот же скрипт для управления записью

3. **Управление записью через сигналы**
   - Переключение записи (старт/стоп) выполняется с помощью сигнала SIGUSR1
   - При получении сигнала скрипт либо останавливает запись и распознает текст, либо начинает новую запись
   - При старте скрипт автоматически начинает запись

4. **Вставка текста**
   - Распознанный текст копируется в буфер обмена с помощью `pyperclip`
   - Затем эмулируется нажатие Ctrl+V с помощью библиотеки `evdev` или `pyautogui`

5. **Уведомления рабочего стола**
   - Использует `notify-send` для отображения уведомлений о начале записи и распознанном тексте
   - Звуковой сигнал при начале записи с помощью `aplay`

## Зависимости

### Системные утилиты

- `arecord` — запись аудио (ALSA)
- `aplay` — воспроизведение аудио (ALSA)
- `notify-send` — отправка уведомлений рабочего стола

### Файлы модели ASR

Необходимые файлы модели должны находиться в директории `./models/`:
- `v3_e2e_ctc.onnx` — основная модель ONNX
- `v3_e2e_ctc_vocab.txt` — словарь модели
- `config.json` — конфигурация модели

## Установка

### 1. Установка uv (рекомендуется)

Для работы с проектом рекомендуется использовать `uv` — быстрый менеджер пакетов Python:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Клонирование репозитория

Скопируйте скрипт на свой компьютер:

```bash
git clone https://github.com/byjk/myhandy.git
cd myhandy
```

Или скачайте архив и распакуйте его в желаемую директорию.

### 3. Установка системных зависимостей

**Debian/Ubuntu:**

```bash
sudo apt-get install alsa-utils libnotify-bin
```

## Использование

### Запуск скрипта

Просто выполните скрипт из директории где он находится:

```bash
uv run myhandy.py
```

При первом запуске скрипт:
1. Создает файл блокировки (по умолчанию `/tmp/myhandy.lock`)
2. Начинает запись аудио
3. Загружает модель ASR
4. Ожидает повторного вызова для остановки/запуска записи

### Переключение записи

Для переключения записи (старт/стоп) просто запустите скрипт снова — он автоматически найдет запущенный процесс и отправит ему сигнал:

```bash
uv run myhandy.py
```

### Завершение работы

Для завершения работы скрипта произнесите слово "Выход." (или другое слово, указанное в переменной окружения `EXIT_WORD`).

### Интеграция с горячими клавишами

Вы можете (нужно!) настроить горячую клавишу в вашей системе для запуска скрипта (мой выбор `Win+Z`):

**GNOME (Ubuntu):**

1. Откройте "Настройки" → "Клавиатура" → "Пользовательские сочетания клавиш"
2. Добавьте новое сочетание:
   - Имя: MyHandy
   - Команда: `/path/to/uv --directory /path/to/myhandy/ run myhandy.py`
   - Сочетание клавиш: например, `Ctrl+Alt+V`

**i3/Sway:**

Добавьте в конфигурационный файл:

```
bindsym $mod+Shift+v exec uv --directory /path/to/myhandy/ run myhandy.py`
```

### Пример рабочего процесса

1. Запустите скрипт в фоновом режиме:
   ```bash
   uv run myhandy.py &
   ```

2. Скрипт начнет запись (услышите звуковой сигнал)

3. Произнесите текст, который хотите ввести

4. Отправьте сигнал для остановки записи:
   ```bash
   uv run myhandy.py
   ```

5. Скрипт распознает речь и вставит текст в активное приложение

6. Для повторной записи запустите скрипт снова

## Переменные окружения

Вы можете настроить поведение скрипта через переменные окружения (все значения также можно задать в файле `.env` в корне проекта — он загружается автоматически при старте, но реальные переменные окружения имеют приоритет):

- `LOCK_FILE` — путь к файлу блокировки (по умолчанию: `/tmp/myhandy.lock`)
- `WAVE_FILE` — путь к временному аудиофайлу (по умолчанию: `/tmp/myhandyrecord.wav`)
- `ARECORD_CMD` — команда для записи аудио (по умолчанию: `arecord -r 16000 -c 1 -f S16_LE -t wav`)
- `BEEP_CMD` — команда для звукового сигнала (по умолчанию: `aplay /usr/share/sounds/sound-icons/glass-water-1.wav`)
- `NOTIFY_CMD` — команда для уведомлений (по умолчанию: `notify-send -t 1 -h boolean:transient:true`)
- `EXIT_WORD` — слово для завершения работы скрипта (по умолчанию: `Выход.`)
- `MODEL_NAME` — имя модели ASR (по умолчанию: `gigaam-v3-e2e-ctc`, будет скачана при первом запуске c hugginface ( ~215Mb ). Список моделей можно посмотреть тут https://istupakov.github.io/onnx-asr/usage/#supported-model-names )
- `MODEL_PATH` — путь к директории с моделью (по умолчанию: `./models`)
- `MODEL_QUANT` — тип квантования модели (по умолчанию: `int8`). Возможные значения: `int8` (8-битное квантование), `` (без квантования). Квантование позволяет уменьшить размер модели и ускорить работу, но может немного снизить точность распознавания.


## Устранение неполадок

### Ошибка "Permission denied" для evdev

Для использования `evdev` может потребоваться добавить пользователя в группу `input`:

```bash
sudo usermod -a -G input $USER
```

Затем выйдите из системы и войдите снова.

### Уведомления не отображаются

Убедитесь, что установлен `notify-send` и работает служба уведомлений:

```bash
notify-send "Тест" "Это тестовое уведомление"
```
